Featured Projects

Core portfolio projects focused on infrastructure, automation, monitoring and defensive Linux practices.

InfraBox

Linux Infrastructure Docker Monitoring
  • Objective: build a local infrastructure monitoring lab on Linux
  • Stack: Debian, Docker, Prometheus, Grafana, Uptime Kuma, Nginx, Samba and OpenSSH
  • Focus: service validation, metrics collection, firewall review and troubleshooting
  • Result: documented monitoring baseline with screenshots, reports and operational notes
  • Repository: github.com/Monte-L/infrabox

NewsWatch Bot

Python FastAPI Automation
  • Objective: create a local news intelligence dashboard using RSS feeds and structured data
  • Stack: Python, FastAPI, SQLite, HTML/CSS/JavaScript, systemd timers and AI summaries
  • Focus: article collection, search, filters, background automation and daily briefings
  • Result: evolving platform prototype with public README and detailed technical reference
  • Repository: github.com/Monte-L/newswatch-bot

Arch Workstation Baseline

Arch Linux Hardening Defensive Security
  • Objective: document and improve a privacy-oriented Arch Linux workstation baseline
  • Stack: Arch Linux, Hyprland, UFW, Fail2ban, NetworkManager, WireGuard-based VPN and Quad9 DNS
  • Focus: firewall validation, VPN/DNS behavior, dotfile sanitization, backup and rollback planning
  • Result: public defensive workstation baseline with sanitized documentation and restore strategy
  • Repository: github.com/Monte-L/arch-workstation-baseline

Debian installation completed

Manual IP configuration in the lab

What was done: configured manual addressing and checked interface information on both systems.

File transfer workflow tested
