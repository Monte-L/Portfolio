# Technical Portfolio

This repository contains a static personal technical portfolio and lab journal used to present hands-on projects in Linux, networking, infrastructure, automation, and defensive security.

The portfolio is built with plain HTML and CSS and is intended to organize my technical learning path, documented projects, study tracks, and contact information in a simple public format.

## Purpose

The goal of this portfolio is to present practical technical development through real projects rather than only listing courses or theoretical study.

It highlights:

- Linux administration practice
- Networking fundamentals
- Infrastructure labs
- Monitoring and observability projects
- Defensive workstation hardening
- Automation and scripting
- Technical documentation
- Lab-based learning progression

## Featured Projects

Main portfolio projects:

| Project | Focus |
|---|---|
| `infrabox` | Linux infrastructure monitoring lab with Docker, Prometheus, Grafana, Uptime Kuma, Nginx, Samba and SSH |
| `newswatch-bot` | FastAPI + SQLite news intelligence dashboard with RSS collection, automation and AI-assisted summaries |
| `arch-workstation-baseline` | Defensive Arch Linux workstation baseline with firewall, VPN/DNS review, dotfiles and backup strategy |
